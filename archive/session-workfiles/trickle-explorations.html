Three dark-mode design explorations from the same lo-fi flow, each answering the "too much text and numbers" feedback differently — A removes and hides, B rewrites numbers as sentences, C keeps the numbers but makes one dominant per screen. Each gives Savings its own distinct visual language, separate from spending.

A — Calm / Minimal

One number does the talking per screen; a full data viz becomes a single ring. Categories and Insight collapse into Home's scroll, so there are fewer places to check. Savings is a filling jar — a shape nothing else on the app uses — set apart from every spending screen. Serif display type for the one number that matters, sans for everything supporting it.

B — Narrative / Conversational

Numbers stay, but they're folded into plain sentences with an inline sparkline instead of being listed as stats. Screens read like a short update, not a spreadsheet. Savings becomes a story you scroll down through — a timeline of contributions toward a goal — instead of a percentage bar. Navigation is swipeable cards rather than a grid.

C — Bold Editorial, Data-First

Doesn't hide numbers — makes one number per screen genuinely huge, everything else shrinks to make room. One dominant chart per screen instead of several small ones. Savings gets its own accent color (yellow) that appears nowhere else in the app, plus a milestone ladder instead of a plain bar, so reaching a goal feels like leveling up.
