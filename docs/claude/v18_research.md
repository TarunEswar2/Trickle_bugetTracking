# v18 research: how budget apps and wallets structure content (10 Oct 2026)

Caveat first: the sources are blog posts, teardowns and design critiques found by web search, plus one model's review (Gemini, pasted by Tarun). None is usability evidence for students. Nothing here says v18 tests better; that needs the recorded student round (RESEARCH.md Part 10).

## Patterns that recur in the sources
1. One hero number per screen, with status folded into it (left to spend, plus "on track") rather than a separate status card.
2. A persistent top bar with a settings/profile icon; settings out of the tab bar.
3. Tab bar with icon + label, 3 to 5 tabs; the main create action is a floating button, not a full-width bar.
4. Category breakdown as one stacked bar or ring, with a list below, not many equal cards.
5. Setup that asks for related things on one screen (amount, split, duration) with a live preview.
6. One accent colour for actions and good state; a second muted colour for secondary data.

## What v18 adopted
- Single split bar replaces slider + preview bar; tap the amounts to type.
- Split and "lasts" dropdown on one screen, with live weekly allowance.
- Icon tab bar, gear in the header, floating Log expense (default), tonal borders, indigo for savings (mint kept for actions), Manrope type, micro share bars on categories.
